新的一年，照例记录下去年一年的流水账。今年元旦时间恰巧和我妈的生日在一块，也就回来过，印象中从上大学开始元旦就没回来过。但我爸妈似乎并不希望我回家，在他们看来我更应该找个对象一起过（唉，以后还是少回）。不过家里的床就是更暖和舒服，妈做的饭也依旧好吃。回归正题，在个人学习计划中，今年确实不如去年，归根结底就是今年太安逸了，倒不是说工作更闲，相反今年要更忙，工作中产出的代码量是去年的 1.5 倍，只是工作表现好反而让我失去了想要奋斗的感觉。

一月，去年一月主要是准备公司的各种年终汇报，再加上临近过年放假确实不想学，在 github 上的贡献只有 8 次，这个时候已经开始准备做 type-challenge 了。没有什么印象特别深的事情，就记得厨房窗外的桂花很香、年终的汇报表现很好。

二月，从这个月开始尝试使用 AI 编辑器 cursor，最早应该是从 v2ex 中看到的，各种铺天盖地的《一个小时实现XXX网站》的帖子，让我想要尝试它。我用 AI 辅助编程还挺早的，23 年初 gpt 出来的时候就注册使用，后来被同事推荐了 tabnine，再后来用通译灵码，我始终感觉 AI 就是一个加强版的搜索引擎。直到年初遇到 cursor，它的 tab 键真的无敌了，而且我尝试了用一句话生成一个程序，效果确实很好，这是我第一个对 AI 编程感到震惊，唯一阻碍我的就是从 webstorm 转到 vscode，快捷键和主题的不同让我用起来很是难受，这个只能慢慢适应。

三月，说来惭愧，ts 已经用了快五年，但是从这个月开始才系统性学习，我开始阅读 ts 文档，了解设计初衷，加上类型体操的练习（感觉 type-challenge 题目更多的是脑筋急转弯），逐渐明晰了简单或者复杂类型的使用场景，使用更好的工具类型和泛型重构代码。除此之外，三月是万物复苏的时候，路边桃花油菜花玉兰花和各种叫不出名字的花都开了，我遇到会拿手机拍一拍，我很喜欢花，我认为想要做出好看的前端也需要寻找美的眼睛，做自己的项目没有设计师帮我设计，我常常想要通过花朵锻炼我的审美，比如观察花瓣数量、渐变颜色或是弧度等（听起来好像比较奇怪）。

四月，这个月猛看全职猎人，一天要看十几集，我一直很喜欢这种剑与魔法世界题材的动漫。其次是了解了 mcp，部门要开 AI 相关的分享会，我讲了这个，但是没讲好，我觉得很牛逼但大家都觉得没什么用，自己也写了一些小 demo，相当于让 agent 学会调接口，挺有趣的。

五月，五一发小 F 来上海找我玩，确实没想到，毕竟很久没联系了，我们从小住在一个小区（从我记事起到现在），我妈和他爸妈是同事，小学初中高中都读的一个学校，学习成绩也差不多，听起来我们关系应该很好，但其实并不，在我眼中我们竞争对手的关系大于朋友，什么都要比，学习要比工资要比，我感觉和他相处时一直戴着面具，因此关系一直是不远不近。游玩三天基本是他带我，印象比较深的是去了徐家汇（真的繁华，一出地铁站就是高楼大厦，真想在这上班），去了海洋公园看到了锯齿鲨（和潜水员戴夫里长得一模一样，很震惊，可惜没拍照）。除此之外是和同事去了南浔，和我想象中的江南水乡一模一样，很开心，景色很不错就是吃的都不好吃。学习方面除了继续 type-challenge，还把 colour-ui 捡起来了，升级了 tailwind 版本，使用方式相比以前简洁了不少。

![nanxun](/post/nanxun.jpg)

六月，端午回家了一趟，给我妈买了点粽子（她真的很喜欢粽子）。之前带我去南浔的同事搬过来一起住了，由于是公司租的房子，经常会有人员流动，一起做饭一起吃饭挺开心的。学习方面，这个月结束了 type-challenge，刷满了 100 题，但中等简单题居多，困难题是真的难，最大的收获是学到了很多 ts 工具类型，诸如 Exclude、Partial，在编写一些工具函数时候很实用。然后是在 colour-ui 中补了几个组件，基本都是在 daisyui 上改的。游戏方面这个月猛玩缺氧，生存建造类游戏，好玩。

七月，猛玩缺氧耽误了学习，这个月差不多玩了 60h，下班玩周末玩，放一张自研氯气巨蕨模块（其实氯气喷出来的时候俩萝北控不住温度，没什么实用性，就是第一次研究这玩意感觉很有意思）。学习方面主要是继续做 colour-ui，有空就做一下。然后是这个月好像是京东和淘宝外卖大战，基本告别了吃了一年半的食堂，天天吃便宜外卖。

![oxygen-not-included](/post/oxygen-not-included.png)

八月，八月主要在做一个项目叫 md-to-pdf，为了解决工作中遇到的 pdf 下载问题，正好 gpt5 刚出，cursor 有免费额度，就试着 vibe coding 了下，效果还不错，就是代码质量确实一般，一个函数几百行，不会提出公共部分，感觉这个时期的 AI 还是比较一般的。这个项目主要难点在于复杂嵌套语法的处理，和中文字体的加载，第二个问题导致了下载 pdf 确实不太好在前端执行，点一下就要加载 20M 的字体文件，即使 pdf 内容很少也需要固定的下载时间，总之就是最终实现了，但是个人觉得适用范围很窄。

九月，丝之歌发售的时间，那自然是猛猛玩这款在我愿望单待了四五年的游戏，游戏是好玩的，但即使是有 300+ 小时一代的经验，玩起来还是很困难，体量很大缺点也不少，打通了之后没有一点想开二周目打钢魂的想法，游戏是好游戏但不适合我。这个月还种了一棵大蒜，很早就有种绿植的想法，但一直没实践，恰巧同事孩子出生发伴手礼，里面有一张种子纸，遂买来花盆楼下挖点土就开种，遗憾的是没有种出任何东西，怀疑是土的问题，就掰了瓣蒜扔进去，谁知长得还不错，之后掐过几次蒜苗炒饭吃，给掐死了。学习方面仍然在做 md-to-pdf，重构了核心逻辑，让代码更好维护，然后完善了 README 发到 npm 上了，第一次在 npm 上发布自己写的东西，还挺顺利的。

十月，国庆节被发小 F 邀着一起去重庆玩，继五一之后的再次联系，我朋友很少，这种被惦记的感觉很不错，结果就是十一和 F 一起去重庆，找另一个朋友 D 玩，重庆确实是山城，各种天桥立交桥很复杂，马路基本都是上坡和下坡，建筑依山而建，朝天门商场从正门进是一楼，上去之后从后面出发现还是一楼，吃重庆火锅，D 说要倒油碟，吃下来实在太油了不适合我，菜也都是辣的，但是各种辣菜很香味道很好，一边斯哈喝水一边吃，很棒的一次旅行。学习方面主要是完善 colour-ui，最终做了十个组件，感觉差不多了，因为原本就是抱着学习目的，接下来会把这十个 tailwindcss 组件，做一版 vue SFC 版本的。

![chongqing-food](/post/chongqing-food.jpg)

十一月，因为快到年终了必然有一些汇报工作，vibe coding 了一个代码统计项目，主要为了量化一年的工作，不然光用嘴说很忙很忙说服力很小，用 electron 结合 git 命令来做的，主要用的 cursor 的 composer-1 模型做的，效果很不错。然后是上个月公司搬到新的地方，环境跟以前比确实好了，这个月就忙着找房子搬家，搬走的时候被究极恶心的中介坑了 600 块。然后是这个月某一天周末去医院加班了一天，带着小朋友用我们开发的产品，看到有多动症很皮的孩子，还有偏瘫坐轮椅的孩子（第一次看到这种，感觉真的挺可怜的），真心希望我们的工作可以帮助他们恢复吧。这个月还读完了《计算机网络自顶向下方法》，要是不做前端了，我倒是想当个网工。

十二月，这个月的八天周末全是在公司度过，可以说一个月都没休息，主要是部门有软著指标，到了年底缺了不少，还不能在工作时间做，不过结果是好的，最终补了二十篇达标了。由于一整个月都在写软著，所以 github 上的贡献基本都是软著代码，都是用 ruoyi 框架或是 figma 生成的，结合 AI 帮忙写，自己学习的东西没怎么做，不过今年学习计划基本达标吧，数据确实不如去年但还算满意，接下来就是要计划 26 年的目标了。游戏方面这个月主要玩 33 号远征队，毕竟拿了 TGA 年度游戏想尝试下，回合制游戏，玩了发现很好玩很适合我，很像阴阳师和星穹铁道，但是操作更多了，一周目打通了，现在二周目还在继续玩。顺便一提月初搬了新家，很不错离公司也近，算是一件开心事。

去年除了 github 贡献变少，写的文档也少了，之前会总结些技术型小功略，去年几乎没写，可能是因为懒，也可能是感觉在 AI 时代，这些都不再有用。今年会更加注重前端工具的学习，再就是读几本书吧，自己的创意小项目可以都撒手了。
